A one-page newspaper front page summing up Thursday 19 November 2026 — the first-ever Trump–Xi–Putin trilateral in Shenzhen, the World Court's genocide ruling against Myanmar, and COP31's draft dropping fossil fuels — drawn entirely in code (flat vector art, no photos) with 43 stories, a DATE CHECK box discarding other days' news, and a "THE DAY IN UTC" timeline.

## Run it

```sh
node main.ts
```

This runs `draw.py` (Python 3 + Pillow) and writes the 1024×1024 front page to `entry.png` (and to `/output/entry.png` when run by the grader). The program is deterministic: running it twice produces byte-identical output.
